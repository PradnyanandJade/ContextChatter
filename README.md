# ContextChatter
Context Chatter is an AI-powered conversational Retrieval-Augmented Generation (RAG) application that enables users to upload documents and interact with them through natural language conversations. By combining semantic search, conversation-aware query rewriting, and large language models,


## ✨ Features

- 📄 Upload and chat with PDF documents
- 💬 Context-aware conversations
- 🔍 Semantic search with FAISS
- 🧠 Query rewriting for follow-up questions
- 🤖 Powered by Hugging Face LLMs
- ⚡ FastAPI backend

## 🛠️ Tech Stack

- Python
- FastAPI
- LangGraph
- FAISS
- Hugging Face
- PyPDFLoader
- BAAI Embeddings
